# F06 — AI 기반 비정형 텍스트 추출

## 개요

보도자료, 뉴스 본문 등 비정형 텍스트에서 이벤트 필드(날짜, 제목, 가격, 링크 등)를 Claude API로 추출한다.

**사용 봇**: convinibot (편의점 신상품), megasale_bot (해외직구 세일)

## 트리거

- 외부 소스(보도자료 HTML, 뉴스)에서 텍스트 수집
- 사전 필터를 통과한 항목에 대해서만 AI 추출 호출

## 사전 필터 (비용 절감)

AI 호출 전에 키워드/날짜 기반 사전 필터를 적용하여 관련 없는 텍스트를 제거한다.

```
수집된 기사 목록
    → 사전 필터 (키워드, 날짜 범위)
    → 필터 통과 목록
    → Claude API 추출
    → 구조화된 이벤트 데이터
```

## AI 추출 계약

Claude API에 보내는 prompt는 다음 필드를 추출하도록 지시한다:

| 필드 | 설명 |
|------|------|
| 이벤트 제목 | 상품명 또는 세일 행사명 |
| 날짜/기간 | 시작일, 종료일 |
| 가격/할인율 | 있는 경우 |
| 원본 링크 | 보도자료 또는 상품 페이지 URL |
| 신뢰도 | 추출 확실성 (high/medium/low) |

## 실패 처리

- 신뢰도 낮음 또는 필수 필드 추출 실패 → 해당 항목 건너뜀
- AI API 오류 → 로그 기록 후 다음 항목으로 진행
- 비용 절감을 위해 같은 항목에 대한 재시도 없음

## 비용 관리 규칙

- 사전 필터 없이 전체 기사를 AI로 보내지 않는다
- API 호출 횟수를 로그로 기록한다
- 모델 다운그레이드(Haiku → Sonnet)로 비용 조정 가능

## 요구사항

- **F06-R1**: 사전 필터를 통과한 항목에만 Claude API를 호출한다
- **F06-R2**: 추출 신뢰도가 낮은 결과는 등록하지 않는다
- **F06-R3**: AI 추출 실패가 봇 전체 실행을 중단시키지 않는다
- **F06-R4**: 사용한 Claude 모델과 호출 횟수를 로그로 남긴다
