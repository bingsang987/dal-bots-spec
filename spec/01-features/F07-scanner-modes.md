# F07 — 스캐너 모드 (신규/변경/만료)

## 개요

laftelbot처럼 콘텐츠 생명주기(신규 공개 → 방영 → 만료)를 전부 추적하는 봇은 여러 스캐너 모드로 나뉘어 실행된다.

## 스캐너 모드 목록

| 모드 | `--mode` 값 | 실행 주기 | 동작 |
|------|------------|----------|------|
| 신규 공개 스캔 | `new` | 매일 | 새로 공개된 콘텐츠 → POST |
| 변경 감지 | `diff` | 매일 | 방영일/정보 변경 → PATCH |
| 만료 처리 | `expire` | 매일 | 서비스 종료 콘텐츠 → description 갱신 또는 DELETE |
| 분기 일정 | `daily` | 분기별 | 분기 편성표 파싱 → Backfill POST |

## 모드별 플로우

### new 모드

```
라프텔 API 신규 콘텐츠 목록 조회
→ DB에 없는 항목 필터
→ POST /events
→ DB 저장
```

### diff 모드

```
DB 내 active 이벤트 목록 로드
→ 각 이벤트에 대해 라프텔 API 현재값 조회
→ content_hash 비교
→ 변경된 항목 PATCH
```

### expire 모드

```
DB 내 이벤트 중 종료일이 오늘 이전인 항목 조회
→ 라프텔 API에서 실제 서비스 종료 여부 확인
→ 종료 확인 시 description에 "(서비스 종료)" 표기 후 PATCH
```

### daily 모드 (Backfill)

```
라프텔 분기 편성표 HTML 파싱
→ DB에 없는 이전 분기 이벤트 확인
→ POST (backfill)
```

## 요구사항

- **F07-R1**: 각 모드는 독립적으로 실행 가능하다 (`--mode` 플래그)
- **F07-R2**: 모드별로 다른 외부 소스 엔드포인트를 호출한다
- **F07-R3**: expire 모드는 DELETE가 아닌 PATCH로 상태를 표시한다 (데이터 보존)
- **F07-R4**: 각 모드는 dry-run을 지원한다
